## 3. 一键重建与自检

```bash
python tools/build.py            # 重新生成全部图片（含演示动图与过程截图）→ 复制到 blog/img/ → 自检
python tools/verify_images.py    # 只做图片自检（尺寸 + 16 个像素探针 + 动图 7 帧 + 博客引用的 12 张插图是否齐全/是否空白图）
python tools/process_shots.py    # 只准备两张过程截图（07 收录 + 08 生成）
python tools/count_words.py      # 统计博客正文字数（要求 800—1200 字）
node tools/check_prototype.js    # 可点击原型自检（需要 Node；6 个界面 + 4 条交互断言）
```

`tools/build.py` 的自检结论（本机已跑通）：

* 9 张图片尺寸正确，16 个关键元素的位置与颜色符合预期（例如「＋ 发布」按钮是主色蓝、流程图的箭头确实画出来了）；
* 演示动图 `09_流程演示.gif` 375 × 868、共 7 帧（1 张标题卡 + 6 个界面）循环播放，约 176 KB；
* 博客正文里引用的 12 张插图（含 `07_制作原型_过程截图.jpg`、`08_画流程图_过程截图.jpg`）都在 `blog/img/` 里、
  尺寸达标且不是空白图——少一张就直接 FAIL，避免贴到博客上才发现是破图；
* `check_prototype.js` 的 12 项断言全部通过，包括「必填项为空时点『发 布』不跳转」这条异常分支；
* 依赖 Pillow（`pip install pillow`）与 Windows 自带字体 `msyh.ttc` / `msyhbd.ttc`；
* 脚本内部还有一层"文字不溢出"校验：任何一个文本超出它的框，脚本会直接报错并指出是哪个元素。

* 原型工具：**墨刀（Modao）**，在线链接 <https://modao.cc/proto/5AmeweAStm2iuwqkXScZBn/sharing?view_mode=read_only&screen=rbpVWVSUILF2FBjjF>

* 配色：主色蓝 `#2f6bff`、寻物橙 `#f79009`、招领绿 `#17b26a`；状态只保留 4 种文案（待认领 / 寻找中 / 已归还 / 已找到）。

* 交互反馈：搜索结果为空、必填项未填、已加载全部、发布成功、状态修改成功、联系方式保护（见博客「六、原型设计」第 4 小节）。
